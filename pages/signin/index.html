Sign in to Glorp from this computer

A login key gets you chat and whispers. Settings that follow your account, whisper history, notifications, /stalk and what you're watching need destiny.gg's login cookies instead. destiny.gg doesn't let web pages read those cookies, so you copy them from your browser here, and this page turns them into a code for Glorp to scan.

This page sends nothing anywhere. The browser won't let it make requests, it stores nothing, and its code is on GitHub.

With a userscript

If you use Tampermonkey or Violentmonkey, the Glorp userscript reads the cookies for you, once the manager is allowed to.

  • In Tampermonkey (5.3 or later), open its Dashboard → Settings, set Config mode to Advanced, then under Security set Allow scripts to access cookies to All.
  • In Violentmonkey, tick Allow GM_cookie to access HTTP-only cookies twice: once in the dashboard's Settings, and once in the script's own Settings tab (open Glorp from the dashboard with its edit button).

(These are their names in Tampermonkey 5.5 and Violentmonkey 2.50; other versions may word or place them differently.) Then reload destiny.gg and choose Sign in to Glorp in the Glorp button's panel in chat, in the manager's menu, or on your profile page. It shows the same code as this page and sends your login nowhere.

By hand

  1. Sign in to destiny.gg in this browser, with Remember me ticked.

  2. On a destiny.gg tab, open the developer tools with F12 or Ctrl+Shift+I. On a Mac it's ⌘+⌥+I.

  3. Find the site's cookies.

    • In Chrome, Edge or Brave, Application tab → Storage → Cookies → https://www.destiny.gg
    • In Firefox, Storage tab → Cookies → https://www.destiny.gg
    • In Safari, turn on Show features for web developers in Settings → Advanced, then Develop → Show Web Inspector → Storage → Cookies

  4. Copy the Value of each of these into the boxes. Double-click a value to select all of it.

    Without rememberme, Glorp gets signed out again when this browser session ends.

  5. In Glorp, open the menu, then Sign in → Sign in from a computer → Scan the code.

Before the code shows

The code is your destiny.gg login. Anyone who scans it, or sees it on a stream or a shared screen, is signed in as you until you sign out on the site.

Your sign-in code

Scan it in Glorp, then hide it. The text works too, pasted into the box under the scan button. The code hides itself if you switch tabs.
