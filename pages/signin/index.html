Sign in to Glorp from this computer

Glorp needs destiny.gg's login cookies for the parts of the site a login key can't open: settings that follow your account, whisper history, notifications, /stalk and what you're watching. destiny.gg keeps those cookies away from web pages, so you copy them from your browser here, and this page turns them into a code for the app to scan.

This page sends nothing anywhere: it isn't allowed to make requests, it stores nothing, and its code is on GitHub.

  1. Sign in to destiny.gg in this browser, with Remember me ticked.

  2. On a destiny.gg tab, open the developer tools: F12, or Ctrl+Shift+I (⌘+⌥+I on a Mac).

  3. Find the site's cookies:

    • Chrome, Edge, Brave: Application tab → Storage → Cookies → https://www.destiny.gg
    • Firefox: Storage tab → Cookies → https://www.destiny.gg
    • Safari: turn on Show features for web developers in Settings → Advanced, then Develop → Show Web Inspector → Storage → Cookies

  4. Copy the Value of each of these into the boxes. Double-click a value to select all of it.

    Without rememberme, the app is signed out again when this browser session ends.

  5. In Glorp: menu → Sign in → Sign in from a computer → Scan the code.

Before the code shows

The code is your destiny.gg login. Anyone who scans it, or sees it on a stream or a shared screen, is signed in as you until you sign out on the site.

Your sign-in code

Scan it in Glorp, then hide it. The text works too: paste it into the box under the scan button. It hides by itself if you switch tabs.
